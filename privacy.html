Privacy Policy – Floating Analog Clock

Effective Date: May 21, 2026

Floating Analog Clock values your privacy. This extension is designed to provide a simple floating analog clock experience without collecting or sharing personal information.

Information We Collect

Floating Analog Clock does not collect, store, transmit, sell, or share any personal information.

The extension does not collect:

  • Personal identity information
  • Names or email addresses
  • Passwords
  • Browsing history
  • Website content
  • Financial information
  • Location data
  • Usage analytics or tracking data

Use of Storage

The extension uses Chrome local storage functionality only to save user preferences and settings including:

  • Clock color preferences
  • Opacity settings
  • Clock position on screen
  • Minimize state
  • Other display customization settings

These settings are stored locally to preserve the user experience across browser sessions.

Data Sharing

  • No data is shared with third parties
  • No information is sold
  • No external data transfer occurs
  • No advertising or tracking technologies are used

Host Permissions

Host permissions are used only to display and maintain the floating clock interface across webpages. The extension does not read, collect, or store webpage content or user activity.

Third-Party Services

This extension does not use third-party analytics services, advertising networks, or external data collection services.

Security

Because the extension does not collect or transmit personal information, no user data is stored on external servers.

Changes to This Privacy Policy

This Privacy Policy may be updated in the future if extension functionality changes. Any updates will be reflected on this page.
